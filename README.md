# GSM-Based Smart Intercom Using ESP32

## Project Overview

This project focuses on the design and development of a GSM-based smart intercom system using an ESP32 microcontroller. It explores the integration of embedded systems, GSM communication, and electronic hardware to enable remote communication through a cellular network.

The project was developed as part of my final-year academic project in Theoretical Physics, with a focus on practical electronics and embedded systems engineering.

## Project Objectives

- Design and develop a GSM-based smart intercom prototype.
- Interface the ESP32 microcontroller with a GSM module.
- Implement serial communication between the microcontroller and GSM module.
- Integrate the electronic components required for the system.
- Test the hardware and troubleshoot integration issues.
